PUBLICATION CONTROL

Approved records only.

Catalogue entries are publication records. A PDF should be linked only after its signed version, public-release status and product metadata have been checked by the responsible GIGA-TMS team.

公開後，主文件 URL 與歷史版本 URL 都是不可變更的公開識別。既有 URL 不替換、不重用，也不改指向其他 PDF；內容更新時，應建立新的版本 URL 並保留舊 URL。

Once published, both the current model URL and the historical archive URL are immutable public identifiers. Do not replace, reuse or retarget an existing URL; issue a new version URL for any update and retain the old URL.

/doc/eu-doc-red/<model>.pdf

Historical version URL：/doc/eu-doc-red/archive/<model>-v<version>-<yyyy-mm-dd>.pdf
