PHASE 2 ARCHITECTURE

One model index.
No family folders.

Future CRA records will be listed in one ascending model-name index. Product family information such as RFID, 125 kHz or GP Series may remain as record metadata, but will not create separate catalogue sections or required URL path segments.

RECORD METADATA

Family information stays
inside the record.

When a CRA model is published, its metadata may identify the applicable product family, frequency or series without changing the single A–Z catalogue structure.

product_family: RFID · 125 kHz · GP Series

Metadata supports verification and document administration; it is not used as a required directory level.

FUTURE URL RULE

Stable model URLs.

After publication approval, each CRA model can receive a stable public URL while historical versions remain traceable in an immutable archive.

/doc/cra/<model>.pdf

Future archive pattern: /doc/cra/archive/<model>-v<version>-<yyyy-mm-dd>.pdf
